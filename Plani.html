DISEÑO Y PLANIFICACION DEL PROYECTO

CLASIFICADOR AUTOMATIZADO

Este diseño simula un proceso industrial de control de calidad.

¿Cómo funciona?: Un objeto avanza por una pequeña banda transportadora. La ESP32-CAM apunta a un punto fijo. Cuando el objeto pasa, la cámara analiza sus píxeles. Si detecta un color específico (por ejemplo, rojo para una pieza defectuosa), envía una señal digital al ESP32 DevKit V1. Lógica de programación: * Cámara: Captura la imagen, segmenta el color usando el espacio de color HSV (Hue, Saturation, Value) y decide si cumple el criterio. DevKit V1: Escucha la señal de la cámara. Al recibir el "alerta de pieza roja", calcula el tiempo de llegada y activa un servomotor 🦾 para desviar el objeto hacia la bandeja de descarte.

SISTEMA DE ACCESO DE RECONOCIMIENTO FACIAL

Este proyecto se enfoca en la seguridad e Internet de las Cosas (IoT).

¿Cómo funciona?: La ESP32-CAM ejecuta un modelo ligero de detección y reconocimiento de rostros (usando la librería estándar esp-face). Compara las facciones de la persona frente a la puerta con una base de datos de rostros previamente guardados en su memoria de destello (Flash) o en una tarjeta MicroSD. Lógica de programación: Cámara: Si el rostro coincide con un usuario autorizado, la cámara envía un comando serial (UART) al DevKit V1 con el ID del usuario. DevKit V1: Recibe el ID, activa un relevador (Relay) para energizar una cerradura solenoide magnética 🔓 durante 5 segundos y, en paralelo, podría encender un LED verde o mostrar un mensaje en una pantalla LCD.

VEHICULO AUTONOMO DE MONITOREO

Este diseño se adentra en la robótica móvil y la navegación autónoma.

¿Cómo funciona?: El vehículo se mueve usando motores de corriente directa (DC). La ESP32-CAM va montada al frente y procesa el entorno en tiempo real para encontrar un "objetivo" (como una línea en el suelo o una pelota que debe seguir). Lógica de programación: Cámara: Calcula el "error de centro". Por ejemplo, si la pelota está muy a la derecha del marco de la foto, la cámara calcula qué tan descentrada está y envía este dato al DevKit V1. DevKit V1: Recibe el valor del error y aplica un algoritmo de control (como un control PID básico) para variar la velocidad de los motores izquierdo y derecho mediante señales PWM (Modulación por Ancho de Pulsos) 🏎‍🟀, logrando que el carrito gire y se centre con el objeto.
